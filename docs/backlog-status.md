## ۵) ریسک و بدهی شناخته‌شده
- PDF فارسی فاکتور → فاز UI (فونت‌ساز)
- اسکن بدافزار mock → ADR آنتی‌ویروس واقعی
- registry قطعی ایمیج‌ها برای تولید (الان mirror)
- Rate-limit لایه وب/Reverse proxy و cursor-pagination → فاز پایدارسازی
- Semgrep/Trivy در CI → فاز امنیت

## ۶) درس‌های اجرایی ثبت‌شده
1. هیچ پچ متنی روی محتوای فارسی — فقط خط‌محور با نشانه ASCII + verify-then-write
2. هر heredoc بدون تو در تو + Parser::ParseFile قبل از اجرا
3. commit فقط پس از سبز شدن تست‌ها
4. شمارش تست با regex فایل تأیید، نه حدس
5. env-check خودترمیم = پایان مشکلات Docker خاموش
