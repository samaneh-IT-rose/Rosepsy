## ۲) موارد فنی معوق (بدهی فنی)

### ۲.۱) APK اندروید
- **دلیل معوق:** build-tools 36 هنوز منتشر نشده (404 در همه منابع) + بلاک dl.google.com
- **وضعیت فعلی:** compileSdk=35 پین شده؛ secure_storage به 9.2.4 تنزل یافت
- **شرح حل:** با دسترسی به dl.google.com (یا VPN) یا انتشار رسمی build-tools 36
- **کد نیازی به تغییر ندارد**

### ۲.۲) دموی مرورگر روی سیستم توسعه‌دهنده
- **دلیل معوق:** preflight pending در شبکه محلی (VPN اکستنشن گوگل / پروکسی)
- **وضعیت فعلی:** کد کامل، build موفق، CORS فعال — صرفاً محیطی
- **شرح حل:** خاموش‌کردن VPN یا تست از دستگاه دیگر در همان Wi-Fi
- **چک‌لیست ۳۰ ثانیه:** در docs/requirements.md §۴۶

### ۲.۳) پیامک واقعی
- **وضعیت فعلی:** DevFixedSmsSender (کد دمو ۱۲۳۴۵۶ فقط در dev) + MockSmsSender (کد در لاگ)
- **شرح حل:** پس از تصمیم D04، کلاس KavenegarSmsSender پشت همان interface

### ۲.۴) درگاه پرداخت واقعی
- **وضعیت فعلی:** MockGateway (کد ثابت success)
- **شرح حل:** پس از تصمیم D02، کلاس ZarinpalGateway پشت همان interface

### ۲.۵) PDF فارسی فاکتور
- **وضعیت فعلی:** PDF حداقلی (فقط ASCII)
- **شرح حل:** نیاز به فونت‌ساز فارسی (Vazirmatn embedded) در فاز UI

### ۲.۶) اسکن بدافزار واقعی
- **وضعیت فعلی:** اسکنر Mock (نام فایل چک می‌شود)
- **شرح حل:** ADR آنتی‌ویروس (ClamAV یا سرویس ابری) — فاز امنیت

### ۲.۷) Push به GitHub
- **وضعیت فعلی:** مخزن لوکال با ۱۵+ commit و tag v1.0.0-alpha
- **دلیل معوق:** دسترسی GitHub در شبکه محدود
- **شرح حل:** git push -u origin main --tags (وقتی دسترسی آزاد شد)

### ۲.۸) CI روی GitHub Actions
- **وضعیت فعلی:** فایل ci.yml آماده (پایپلاین سه‌سرویسی)
- **شرح حل:** خودکار پس از push — نیازی به کار اضافه نیست

### ۲.۹) رفع خطای «Initialize containers» در CI
- **دلیل معوق:** توکن فعلی GitHub فاقد `workflow` scope است؛ push هر تغییری در
  `.github/workflows/*` رد می‌شود
- **شرح مشکل:** سرویس `quay.io/minio/minio:latest` روی رانرهای GitHub با
  «unauthorized» رد می‌شود و job از همان گام Initialize containers می‌افتد
  (در اجراهای قبلی هم همین بود)
- **راه‌حل آماده:** `docs/ci-workflow-fixed.yml` — MinIO از باینری رسمی
  dl.min.io اجرا می‌شود (مستقل از رجیستری). کافی است محتوای آن جای
  `.github/workflows/ci.yml` گذاشته و با توکن دارای workflow scope پush شود:
  ```bash
  cp docs/ci-workflow-fixed.yml .github/workflows/ci.yml
  git add .github/workflows/ci.yml && git commit -m "ci: binary MinIO" && git push
  ```
